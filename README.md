# Альфа-Курс · Telegram-помощник

Прототип для трека 2 Hack&Change 2026. Помощник отвечает по базе «Альфа-Курса», подбирает материалы для предпринимателей, запоминает их явно названные предпочтения и ведёт напоминания.

## Запуск через Docker

1. Запустите Docker Engine или Docker Desktop. Скопируйте .env.example в .env и задайте BOT_TOKEN. Токен тестового бота выдаёт [@BotFather](https://t.me/BotFather).
2. Из корня проекта выполните **docker compose up --build**.
3. Дождитесь готовности Telegram и успешного завершения сервиса bootstrap, затем отправьте боту **/start**.

Compose запускает PostgreSQL с pgvector и Ollama, скачивает модели, применяет миграции и собирает индекс. Telegram и планировщик запускаются после миграций. Первый запуск требует сети для скачивания образов и около 3,1 ГБ весов. Выделите Docker память для моделей, приложения и БД. На CPU первый ответ может занять несколько минут. Telegram Bot API подключается токеном. Локальные модели обходятся без API-ключей.

При пустых SOURCE_DATABASE_URL и KB_MATERIALS_PATH свежая база загружает синтетический демонабор из demo/materials.jsonl. Карточки и ссылки в нём демонстрационные. Для проверки на материалах организаторов используйте [инструкцию импорта дампа](docs/INTEGRATION.md).

## Сценарий проверки

| Что сделать | Что проверить |
| --- | --- |
| «Как привлечь первых клиентов в кофейню?» | Ответ из демобазы и кликабельный источник |
| «Я только открываю кофейню, отвечай коротко, без курсов. Как привлечь первых клиентов?» | Краткий ответ без курса |
| После /new: «Подбери платный курс по маркетингу кофейни и планированию рекламных кампаний» | Карточка подходящего курса с описанием и ссылкой |
| «Какие требования к франшизе кофейни в Сингапуре?» | Честное сообщение о нехватке данных |
| «Напомни через 2 минуты по МСК проверить каталог». Подтвердите черновик | Сообщение приходит после назначенного времени с учётом интервала проверки |
| «Напоминай ежедневно в 10:00 МСК продолжить обучение». Подтвердите и откройте /reminders | Частоту можно изменить, напоминание — отключить |

Команда /cancel отменяет текущее уточнение или черновик. Команда /new очищает историю и профиль. Подтверждёнными напоминаниями управляет /reminders.

## Архитектура

    src/alfa_bot/
    ├── adapters/telegram.py       Telegram, ссылки, кнопки
    ├── assistant/
    │   ├── service.py             интент, поиск и ответ по источникам
    │   ├── personalization.py     профиль, формат и рекомендации
    │   ├── prompts.py             инструкции модели
    │   └── repository.py          история и ожидаемое уточнение
    ├── knowledge/
    │   ├── ingest.py              команда импорта
    │   ├── source_postgres.py     чтение открытых материалов из дампа
    │   ├── corpus.py              очистка HTML и чанкинг
    │   ├── index_postgres.py      векторы и запись снимка
    │   └── retrieval.py           cosine-поиск и фильтры
    ├── reminders/                 расписание и доставка
    ├── contracts.py               общие DTO и AssistantPort
    ├── infra/                     PostgreSQL, Ollama и настройки
    └── main.py                    сборка зависимостей

Три логических модуля работают в одном приложении. Telegram вызывает AssistantPort. Ассистент ищет через KnowledgePort, передаёт профиль и найденные фрагменты модели, проверяет ID источников. Статьи, документы и глоссарий дают текст для ответов. Курсы участвуют через публичные карточки. Подтверждённые напоминания хранятся в PostgreSQL.

## Конфигурация

| Переменная | Назначение |
| --- | --- |
| BOT_TOKEN | Токен Telegram, обязателен для запуска бота |
| DATABASE_URL, POSTGRES_PASSWORD | Адрес БД при запуске с хоста и пароль БД Compose. Compose использует db:5432 |
| SOURCE_DATABASE_URL | Отдельная БД с восстановленным дампом |
| KB_MATERIALS_PATH | Альтернатива исходной БД, JSONL под /app/private_data/ |
| OLLAMA_BASE_URL, LLM_MODEL, EMBEDDING_MODEL | Локальный Ollama, модели qwen2.5:3b и bge-m3:567m по умолчанию |
| OLLAMA_CONTEXT_LENGTH, LLM_TIMEOUT, EMBEDDING_TIMEOUT | Контекст модели в токенах, таймауты в секундах |
| CHUNK_SIZE_TOKENS, CHUNK_OVERLAP_TOKENS | Размер и перекрытие, 600 и 50 токенов оценочного токенизатора |
| KB_TOP_K, KB_SCORE_THRESHOLD, KB_CATALOG_SCORE_THRESHOLD | До 5 фрагментов. Пороги cosine 0,60 для ответа и 0,55 для каталога |
| ARTICLE_URL_TEMPLATE, DOCUMENT_URL_TEMPLATE, GLOSSARY_URL_TEMPLATE, COURSE_URL_TEMPLATE | Маршруты платформы для формирования URL из slug |
| OLLAMA_MAX_LOADED_MODELS | Число моделей в памяти. По умолчанию 1 для экономии памяти |
| LOG_LEVEL, REMINDER_INTERVAL | Уровень логов и интервал проверки напоминаний в секундах |

В Compose PostgreSQL слушает порт 5432, Ollama — 11434. Порты доступны внутри сети стека. Зависимости Python зафиксированы в uv.lock.

## Разработка и ограничения

    uv sync --locked --extra dev
    uv run pytest -q
    uv run ruff check .

- Храните дамп и подготовленные материалы локально под private_data/.
- Бот рассчитан на личный чат и один процесс Telegram polling. Подтверждённые напоминания переживают перезапуск. Черновик с кнопками живёт в памяти процесса.
- Большой корпус требует времени на CPU. После смены модели эмбеддингов пересоберите индекс.
- База отражает состояние материалов на момент выгрузки. Для вопросов о действующих налоговых сроках и правовых нормах нужен свежий источник. Точность ответа по найденным фрагментам оценивается размеченными сценариями.
