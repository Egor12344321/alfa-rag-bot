# Проверки

Текущие тесты проверяют разделение liveness/readiness и отсутствие успешного
подтверждения несохранённого webhook. Добавлять тесты бизнес-логики вместе
с реализацией: ограничения доступа, ссылки, repeat/DST, idempotency, отмена,
конкуренция и восстановление. Реальная БД с pgvector нужна для интеграционных тестов.
