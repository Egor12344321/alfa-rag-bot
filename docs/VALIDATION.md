# Проверка каркаса

Проверено при создании 11 ноября 2026 года:

- Зависимости разрешены в uv.lock, окружение установлено через uv sync --frozen.
- Экспортирован requirements.txt с хешами для Docker.
- uv lock --check подтвердил актуальность lock-файла.
- Ruff: все проверки пройдены; Python-файлы отформатированы.
- Pytest: 2 теста пройдены. Проверены liveness/readiness, закрытие ресурса БД,
  проверка webhook secret и отсутствие успешного подтверждения несохранённого update.
- Alembic upgrade head --sql сформировал SQL; pglast разобрал 38 операторов.
  Рабочая схема содержит 15 таблиц плюс служебную таблицу версии Alembic.
- Compose YAML разобран; SOURCE_DATABASE_URL передаётся только ingest.
- CLI --help проверен у ingest, worker и polling.

Ограничения проверки:

- Docker/Compose и реальная PostgreSQL с pgvector в этом окружении не запускались.
- Миграция проверена генерацией и разбором SQL, без выполнения на реальной БД.
- Telegram, embeddings, генерация, планирование и доставка ещё не реализованы.
- Дамп и его DDL не входят в пакет; mapping и политика доступа требуют проверки
  по реальным таблицам и значениям справочников.

Документ описывает проверки каркаса, а не готовность бизнес-сценариев бота.
